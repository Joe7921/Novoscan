简单来说，Novoscan 是做什么的？

想象一下：你有一个创新想法（比如一款新产品、一项新技术、一个新商业模式），你想知道这个想法到底靠不靠谱、值不值得投入。 传统做法是找几个专家开会讨论，但专家贵、时间长、意见主观。

Novoscan 做的事情就是：用 AI 代替专家团来评估你的创新方案。 它会自动派出多个 AI "专家"——有的从学术角度看、有的从市场角度看、有的专找竞品对比。 然后这些 AI 专家还会像真人开会一样互相辩论、互相挑战，最后由一个"仲裁官"综合所有意见，给出一份结构化的评估报告。

跟市面上其他 AI 工具的区别在于：别的工具让一个 AI 直接给你打分（容易片面）， 而 Novoscan 让多个 AI 先吵一架再打分——通过对抗和辩论，结论更全面、更可信。 下面的内容会详细展示这套系统是怎么运作的。

Core Feature 02

Agentic Workflow 智能体工作流

业界独特的双 Studio 模式——Standard 编译工作流 + Agentic 智能体工作流，一键切换

Standard Mode

编译工作流 Studio

Dify 同款——可视化拖拽设计固定拓扑管线，Pipeline JSON 通过编译器编译为 LangGraph StateGraph

  • 确定性执行路径，节点顺序预定义
  • 支持条件边（评分分差触发辩论）
  • interrupt_before 实现 HITL 人工审核
  • 管线保存/加载/导出 JSON
  • 适合生产环境稳定部署
Agentic Mode

智能体工作流 Studio

超级 ReAct Agent 将全部积木暴露为 Tool，LLM 自主决定调用顺序和次数

  • LLM 自主编排工具链，动态决策
  • Agentic 调优助手——ReAct 策略调优、工具链诊断、Token 预估
  • 画布内实时试运行，节点状态动态标记
  • max_iterations 安全防护
  • 适合探索性研究与复杂场景
同一套三层积木，两种运行方式无缝切换——兼顾可控性与灵活性

YAML 驱动 · 零代码开发

所有积木通过 YAML 声明——只需填写 id、name、inputs、outputs、config_schema，即可创建全新 Agent

  • Agent：YAML 定义角色 Prompt、输入输出字段、温度等参数，自动注册到 BlockRegistry
  • Tool：YAML 声明 local / http / mcp 三种类型工具，支持 CRUD + 导入导出
  • Pipeline：JSON 定义管线拓扑，通过 PipelineCompiler 编译为可执行 LangGraph 图
  • Report：YAML 声明报告 sections + 可视化组件类型，自动组装结构化输出
  • 双重接口：每个 AgentBlock 同时是 Graph Node + LangChain Tool，一套逻辑两种调用方式

Advantages

核心竞争力总结

架构、产品、生态三个维度的差异化优势

🔓 完全开源 · Apache 2.0

Apache 2.0 协议，支持完全自定义版本的 Novoscan。简单部署、下载安装即可使用，零门槛上手。

  • 完整源码开放，企业可自由二次开发
  • 简单部署——uv sync + uvicorn 一条命令启动
  • 支持 Docker 容器化部署

🔌 模型无关 · 通用协议

统一 OpenAI-Compatible 协议，严禁硬编码——一套代码适配所有主流模型。

  • DeepSeek / MiniMax / Moonshot / 本地 Ollama 无缝切换
  • 主/备模型三级降级容错
  • 仅需修改 .env 即可切换模型

🎨 双 Studio 模式 · 自然语言开发

Dify 同款 Standard Studio + 独创 Agentic Studio，对话式 AI 助手自然语言设计工作流。

  • 可视化拖拽设计管线，非开发者也能上手
  • Agentic 调优——ReAct 策略、Token 预估、工具链诊断
  • 画布内实时试运行，节点状态动态标记

🏪 插件市场 · 一键贡献

与云端版插件市场深度互联，用户开发的高价值内容可以被很好地内化和共享。

  • 一键贡献——将本地 Agent / Tool / Pipeline 上传市场
  • 从社区导入高质量管线模板
  • 自开发积木与云端版双向同步

🧩 三级插件 · 积木化自定义

管线 → Agent → Tool → 报告，全链路积木化，真正做到各行各业自定义适配。

  • YAML 零代码创建任意积木
  • _builtin + _custom 双目录热插拔
  • 六层十类角色体系覆盖完整 AI 工作流

⚔️ 多Agent辩论 · 对抗验证

独创的 LangGraph 子图辩论引擎，正反方对抗 + 主持人裁判 + K.O. 机制。

  • 评分分差 > 20 自动触发辩论
  • 每个 Agent 独立 LLM 调用，真对抗
  • 连胜 2 轮 K.O. 终止，保证效率
